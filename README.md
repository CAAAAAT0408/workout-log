# 운동관리 (https://caaaaat0408.github.io/workout-log/)

근력 운동의 종목·세트·중량·회수와 유산소 시간, 체성분을 적고 날짜별·월별 변화를 그래프로 보는 한 페이지짜리 기록장입니다.
주소만 열면 누구나 쓸 수 있습니다. 처음 열 때 이름과 비밀번호를 정해 등록하면, 사람마다 기록을 따로 보관합니다
(서버에 가입하는 것이 아니라, 쓰는 기기 안에서만 통하는 이름과 비밀번호입니다).

## 할 수 있는 것
- **기록**: 날짜 → 종목 → 세트 수 → 세트별 중량·회수. 종목 총중량과 그날 총중량(중량 × 회수의 합)을 바로 계산
- 종목은 직접 입력. 한 번 저장한 종목은 버튼으로 나오고, 고르면 직전 기록이 세트별로 보임
- **유산소**: 종목과 시간(분)
- **통계**: 날짜별·월별 총중량, 종목별 최고 중량·총중량 변화, 유산소 시간
- **체성분**: 체중·골격근량·체지방량(체지방률 자동 계산)과 변화 그래프
- **엑셀 받기**: 운동일지(날짜 묶음 양식), 날짜별·월별·종목별 합계, 유산소, 체성분, 세트 기록 시트
- **사람 구분**: 이름 + 직접 정한 비밀번호로 등록. 한 기기를 여럿이 써도 각자 기록만 열리고, 사람 바꾸기·비밀번호 바꾸기·내 기록 지우기 가능
- 폰·PC 화면 모두 대응. 홈 화면에 추가하면 앱처럼 열리고, 한 번 연 뒤에는 인터넷이 약한 곳에서도 열림

## 기록이 저장되는 곳
- 기록은 **쓰는 사람의 브라우저에만** 저장됩니다. 서버로 보내지 않습니다.
- 사람마다 기록 묶음을 따로 두고, 그 사람의 비밀번호에서 뽑은 열쇠로 잠급니다(PBKDF2-SHA256 15만 회 → AES-GCM).
  localStorage: `wl2.people`(이름 목록) · `wl2.db.<id>`(잠긴 기록) · `wl2.sess`(열어 둔 사람의 열쇠 — 로그인 유지를 끄면 sessionStorage). 비밀번호 자체는 저장하지 않습니다.
- **비밀번호를 잊으면 기록을 되찾을 수 없습니다.** 백업 파일이 있으면 새 이름으로 등록한 뒤 불러올 수 있습니다(백업 파일은 잠겨 있지 않음).
- 기기끼리 저절로 맞춰지지 않습니다. 같은 이름으로 다른 기기에서 등록해도 기록은 따라오지 않으며, 옮길 때는 페이지 맨 아래
  **백업 · 다른 기기로 옮기기**에서 백업 파일을 받아 그 기기에서 불러옵니다. 같은 날짜가 양쪽에 있으면 더 나중에 고친 쪽이 남습니다.
- 브라우저 데이터를 지우면 기록도 지워집니다. 가끔 백업 파일을 받아 두세요(30일 넘게 안 받으면 페이지가 알려 줍니다).
- 아이폰·아이패드는 공유 버튼의 **홈 화면에 추가**로 설치해 쓰는 것이 안전합니다. 사파리 탭으로만 쓰면 7일 넘게 열지 않았을 때 사파리가 저장분을 지울 수 있습니다.
- v1.0(사람 구분 전)에 이 기기에 쌓인 기록은 처음 등록하는 이름이 이어받습니다.

## GitHub 에 올리기 · 배포
- 저장소 https://github.com/CAAAAAT0408/workout-log (Public) → 사이트 https://caaaaat0408.github.io/workout-log/
- 저장소 Settings → Pages 의 Source 는 **GitHub Actions** 입니다. `main` 에 올리면 `.github/workflows/pages.yml` 이
  저장소 내용을 그대로 사이트로 내보냅니다(1분쯤). 결과는 저장소 Actions 탭의 「Pages 배포」에서 봅니다.
- PC 에서 고쳐 올릴 때는 이 폴더의 `깃허브 올리기.bat` 을 실행합니다(커밋 + push).
- 다른 자동화 도구처럼 Branch `main` / `(root)` 방식으로 바꾸려면 Pages 의 Source 를 "Deploy from a branch" 로 바꾸고 워크플로 파일을 지웁니다.

## 버전과 수정 이력
- 자동화 도구들과 같은 규칙(최초 1.0, 수정 1회 +0.1): `python bump_version.py workout "수정 내용"`
  → `version.json` 과 브라우저 탭 제목·머리글의 `_v1.N` 이 함께 바뀐다.

## 파일
- `index.html` — 페이지 전체(화면·계산·저장). 엑셀 파일을 만들 때만 ExcelJS 를 CDN 에서 불러온다.
- `sw.js`, `manifest.webmanifest`, `icon-*.png`, `apple-touch-icon.png` — 홈 화면 추가와 오프라인 사본
- `version.json`, `bump_version.py` — 버전·수정 이력
- `깃허브 올리기.bat` — 바뀐 파일을 커밋하고 올림
- `.github/workflows/pages.yml` — main 에 올리면 사이트에 반영(배포)
